# Steel & Code — Programming Fundamentals I

## Self-Paced Product Definition

## Product Name

**Programming Fundamentals I: Python, Automation & Computational Modeling**

## Product Type

Self-paced online course

## Delivery Model

Students move through the course independently using the Steel & Code learning platform and Workbench.

The course follows a suggested 8-week path, but students may move faster or slower depending on their schedule and experience.

---

# Product Promise

Learn programming by solving problems, automating repetitive tasks, and building computational models with Python.

This course is designed for beginners who want to understand how programming works and how it can be applied to real-world problems.

The course focuses on:

- Problem solving
- Programming logic
- Automation
- Python fundamentals
- Computational modeling
- Applied projects
- Building confidence through practice

The emphasis is on learning the process of programming rather than memorizing syntax.

---

# Target Student

This course is designed for:

- Complete beginners
- Career changers
- College students
- Technical professionals who want Python fundamentals
- Students who struggle with traditional programming courses
- Learners who prefer hands-on instruction
- Learners interested in automation
- Learners interested in applied computational modeling

No prior programming experience is required.

---

# Suggested Completion Time

**8 weeks**

Students should expect approximately:

**3–5 hours per week**

Estimated total course effort:

**25–35 hours**

Because the course is self-paced, students may complete it faster or take additional time as needed.

---

# Course Structure

The course contains:

- 4 major modules
- Approximately 32 short instructional videos
- Guided coding examples
- Steel & Code Workbench labs
- Independent coding challenges
- Knowledge checks
- 4 module projects
- 1 computational modeling capstone

---

# Course Modules

## Module 1 — Foundations

Students learn:

- How programs work
- Variables
- Data types
- Input and output
- Operators
- Expressions
- Type conversion
- Translating formulas into Python

### Project

Build a real-world calculator.

---

## Module 2 — Decisions

Students learn:

- Boolean logic
- Comparison operators
- `if`
- `else`
- `elif`
- `and`
- `or`
- `not`
- Nested conditions

### Project

Build a decision system.

---

## Module 3 — Repetition and Automation

Students learn:

- `while` loops
- `for` loops
- `range()`
- Counters
- Accumulators
- Input validation
- Repetitive task automation
- Introductory iterative modeling

### Project

Automate a repetitive problem.

---

## Module 4 — Building Programs

Students learn:

- Functions
- Parameters
- Return values
- Lists
- Basic file handling
- Organizing larger programs

### Project

Build a multi-part Python application.

---

# Computational Modeling Capstone

Students finish the course by applying everything they learned to a real-world problem.

The capstone follows the process:

**Problem → Variables → Relationships → Algorithm → Python → Results → Interpretation**

Possible project areas include:

- Engineering
- Finance
- Science
- Business
- Everyday automation

The goal is not simply to write code.

The goal is to use programming as a tool to understand and solve a real problem.

---

# Student Learning Experience

Each lesson follows the Steel & Code learning model:

**Learn → Watch → Build → Practice → Apply**

---

## Learn

Students receive a short explanation of the concept.

---

## Watch

Students watch a worked example with instructor commentary explaining the reasoning process.

---

## Build

Students open the example in the Steel & Code Workbench and code alongside the lesson.

---

## Practice

Students complete an independent challenge based on the same concept.

---

## Apply

Students use the concept in a real-world scenario.

---

# Video Format

Videos should generally be:

**8–15 minutes**

Approximately:

**4 videos per suggested week**

Video types include:

- Concept explanation
- Worked example
- Guided build
- Applied example
- Computational model
- Project walkthrough

Videos should remain focused and avoid long traditional lectures whenever possible.

---

# Steel & Code Workbench

Students use the Steel & Code Workbench throughout the course.

The Workbench allows students to:

- Write Python code
- Run Python code
- Test examples
- Modify instructor examples
- Complete guided labs
- Complete independent challenges
- Experiment with models

Lesson pages should provide direct access to relevant Workbench examples whenever possible.

---

# Guided Labs

Guided labs reinforce concepts immediately after instruction.

Examples may include:

- Tip calculator
- Pay calculator
- Temperature converter
- Ohm's Law calculator
- Grade classifier
- Equipment threshold monitor
- Loop-based automation
- Growth model
- Function-based calculator
- File-processing exercise

Labs should emphasize understanding and experimentation rather than simply copying code.

---

# Independent Challenges

Each lesson should include a small challenge that requires students to apply the concept without following the exact instructor example.

Challenges should generally:

- Take 10–30 minutes
- Reinforce one or two concepts
- Require some independent thought
- Provide optional hints
- Avoid unnecessary complexity

---

# Knowledge Checks

Lessons may include short knowledge checks.

Typical knowledge checks include:

- Multiple-choice questions
- Predict the output
- Identify the error
- Explain what code does
- Select the correct algorithm
- Short coding questions

Knowledge checks should reinforce understanding rather than act as high-stakes exams.

---

# Module Projects

Each major module ends with an applied project.

Projects should require students to combine concepts learned throughout the module.

Students should receive:

- Project scenario
- Requirements
- Expected behaviors
- Testing guidance
- Optional hints
- Completion checklist

Where appropriate, students may be encouraged to customize the project.

---

# Capstone Experience

The capstone should require students to demonstrate the complete programming process.

Students should:

1. Understand the problem
2. Identify required inputs
3. Identify expected outputs
4. Determine mathematical or logical relationships
5. Design an algorithm
6. Build the Python solution
7. Test the solution
8. Run multiple scenarios
9. Interpret the results
10. Explain their approach

---

Exact access duration may be determined separately from the instructional design.

- One-year access
- Six-month access

---

# Completion Requirements

A student should be considered to have completed the course after completing:

- Required lesson activities
- Guided labs
- Four module projects
- Computational modeling capstone

A traditional percentage grade is not required for self-paced learners.

Completion should emphasize demonstrated application of skills.

---

# Certificate

Students who complete the required course work may receive a Steel & Code certificate of completion.

The certificate should identify:

**Programming Fundamentals I: Python, Automation & Computational Modeling**

The certificate should represent course completion and should not imply professional certification or accreditation.

---

# Student Outcomes

By the end of the course, students should be able to:

- Explain how basic programs operate
- Use variables and common Python data types
- Accept and process user input
- Write calculations and expressions
- Use conditional logic
- Use loops to automate repetitive work
- Write and call functions
- Work with basic collections
- Read and write simple files
- Break problems into smaller steps
- Test and debug basic Python programs
- Build multi-part Python applications
- Translate real-world relationships into code
- Build introductory computational models
- Interpret program output in the context of a real problem

---

# What This Course Does Not Cover

PF1 should remain focused.

The self-paced course does not need to deeply cover:

- Object-oriented programming
- Web development
- APIs
- Databases
- Data science libraries
- GUI development
- Advanced file processing
- Software architecture
- Deployment
- Advanced testing
- Frameworks

These topics may be introduced in future Steel & Code courses.

---

# Product Boundaries

The self-paced PF1 product should not become an endless collection of Python topics.

Version 1.0 should remain focused on:

**Programming Fundamentals + Automation + Computational Modeling**

The product is complete when students can move from:

**Problem → Logic → Code → Working Solution → Interpretation**
