FLAGSHIP COURSE

Python Programming Fundamentals

Learn the process, not just the syntax. Break problems down, build solutions in Python, and automate repetitive work through real-world exercises.

Build the foundations

  • Use variables, collections, loops, and functions to solve problems.
  • Read and write files, organize data, and work with CSV records.
  • Debug step by step and check that your code does what you intend.

Put Python to work

  • Organize files and automate repeatable tasks.
  • Clean data and turn raw records into useful summaries.
  • Build small scripts, test them, and refine them as requirements change.

Start where you are. Work through a problem, understand why the solution works, then simplify it. Teach, refine, simplify.
