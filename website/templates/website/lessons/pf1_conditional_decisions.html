PROGRAMMING FUNDAMENTALS I · MODULE 2: CONDITIONAL DECISIONS

Making Decisions with if, elif, and else

Objective: Use conditional statements to make a Python program respond differently based on data.

How Python chooses a path

A condition is a test that is either true or false. In an if/elif/else chain, Python checks conditions from top to bottom and executes the first matching branch. It then skips the remaining branches in that chain.

if starts the first test. elif means “else if” and checks another condition when earlier tests were false. else has no condition: it runs when none of the earlier conditions matched.

End each branch header with a colon and indent its instructions by four spaces. The indentation tells Python which instructions belong to that branch.
